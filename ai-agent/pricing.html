FAQ

常见问题

平台会接触我的资金吗？

不会。资金始终在你的 Binance 账户，平台只用 API Key 代你下单（只交易权限，不提现）。

订阅费是按月还是按收益？

默认按月订阅。创作者也可以选择"按收益分成"模式（10-30%）。

能随时取消订阅吗？

可以。取消后下月生效，已付费用不退，但 Agent 会立即停止执行。

普通用户能升级为创作者吗？

可以。提交申请 + 实名认证 + 审核通过后即可升级，开始发布策略赚分成。

策略亏损了怎么办？

平台不保证收益。建议订阅前看历史回测 + 模拟订阅 7 天，并设置止损风控。

Pro 版值得升级吗？

订阅 3 个策略以上、需要高级触发条件或 Agent 对话功能就值得。否则免费版够用。
